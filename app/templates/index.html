演练脚本（建议按此验证两条关键路径）
  1. 前班占用 → 窗口内补建：10:00 触发调度建出 Job；推进到 10:10 后再触发，10:10 班显示“等待前班”；推进 1~2 分钟并结束前班 Job，再触发 → 10:10 班在 10:13 截止前“已建”。
  2. 超期等待 → 跳过：保持前班运行，把时钟推进到 10:13 之后并触发，本班记“已跳过（前班未结束/满 3 分钟）”。
  3. 丢回执 + 超期 + 查回：在某个备份库卡片上“布置一次性丢回执”，在窗口内触发调度：集群 Job 已建但页面拿不到 ID；把时钟推过 3 分钟再触发，班次记跳过且标红“回执丢失”；点“查回集群 Job”或“一键查回”，即可按幂等键找回集群原始 Job，班次转为“已建（查回）”。
  4. 并发：可对同一时刻连续/并发点多次“触发调度”，或用仓库中的 tests/e2e_http.py 并发打接口；每班仍至多一个 Job，同库至多一个 RUNNING。
  5. 清理结案班次：演练跑久后，在上方 ③ 选备份库、填保留班数（可填 0）再点清理：按到点时间保留最新 N 班结案班次，其余结案班次连同调度尝试一并删除并显示删了几班；清理后推进时钟/再调度/重启都不会重建已删班次。
